Custom Styling

The palette in JS#1 uses CSS custom properties, which allows for theme-based styling without hardcoding colors:

"popup": {
     "background": "var(--theme-primary)",
     "text": "var(--theme-text)"
 },
 "button": {
     "background": "var(--theme-accent)",
     "text": "var(--theme-text)"
 }

This means you can control the banner's appearance from CSS, like:

:root {
  --theme-primary: #2e3a59;
  --theme-text: #ffffff;
  --theme-accent: #fbbc05;
}
